# تحدي عكس الصوت (Reverse Voice Challenge) 🎙️🔄

لعبة ويب متكاملة وتفاعلية في **ملف واحد فقط (`index.html`)** تعمل بالكامل على المتصفح بنظام اللعب الجماعي اللحظي (Real-time Multiplayer) دون الحاجة لأي خادم وسيط (Serverless / Static).

---

## 🌟 المميزات الرئيسية
1. **واجهة مظلمة عصرية (Cyber Dark Theme):**
   - تصميم عربي بالكامل RTL باستخدام خطي `Cairo` و `Tajawal`.
   - مؤثرات Glassmorphism وتدرجات نيون ديناميكية وموجات صوتية تفاعلية على HTML5 Canvas.
   - متجاوبة 100% مع الهواتف الذكية والأجهزة اللوحية والحواسيب.

2. **معالجة الصوت في الوقت الفعلي (Web Audio API):**
   - تسجيل المايكروفون بجودة منخفضة الحجم (Mono 16kHz WAV PCM) لتوفير البيانات وسرعة النقل.
   - خوارزمية عكس مصفوفة الصوت (`AudioBuffer.getChannelData().reverse()`).
   - تشغيل الصوت الأصلي والصوت المعكوس فوراً.
   - عكس تقليد المنافس مجدداً للكشف عن مدى مطابقة الصوت للكلمة الأصلية!

3. **غرف اللعب الجماعي أونلاين (Online Multiplayer):**
   - إنشاء غرفة وتوليد كود من 5 أرقام مع رابط مشاركة مباشر (`?room=12345`).
   - زر نسخ الرابط ومشاركته عبر واتساب بنقرة واحدة.
   - مزامنة فورية عبر **Firebase Firestore** لتبادل الأصوات وحالات الجولات.
   - **الوضع المحلي التجريبي (Local / Multi-tab fallback):** يمكنك فتح المتصفح في تبويبين وتجربة اللعبة فوراً حتى بدون ربط Firebase!

4. **ميزات إضافية:**
   - **بنك كلمات ضخم ومولد أفكار عشوائي:**
     - أسماء الصحابة رضوان الله عليهم.
     - كلمات صعبة ومعقدة النطق بالعكس.
     - أمثال شعبية وتحديات لسان.
     - أكلات ومصطلحات طريفة.
   - **لوحة نقاط لحظية (Leaderboard):** تحكيم المحاولات واحتساب النقاط وتبديل الأدوار آلياً بين اللاعبين.
   - مؤثرات صوتية مبنية بـ Web Audio API واحتفالات Confetti.

## 🚀 كيفية الرفع على Netlify أو Vercel

الملف جاهز ومستقل تماماً ولا يحتاج إلى أي Build Step أو تثبيت حزم Node:

### 1. الرفع على Netlify (الأسهل والأسرع):
1. ادخل على [Netlify Drop](https://app.netlify.com/drop).
2. اسحب مجلد المشروع (الذي يحتوي على `index.html`) وافلته في الصفحة.
3. مبروك! ستحصل على رابط حي ومباشر خلال ثوان.

### 2. الرفع على Vercel:
1. ثبت Vercel CLI أو ارفع المشروع إلى مستودع GitHub.
2. قم بعمل استيراد للمشروع في Vercel مع ترك إعدادات الـ Framework على "Other".
3. انقر **Deploy**.

## 🔥 إعداد Firebase Firestore (للعب بين جهازين عبر الإنترنت)

إذا أردت اللعب بين هاتفين أو جهازين مختلفين عبر الإنترنت:
1. ادخل إلى [Firebase Console](https://console.firebase.google.com/) وأنشئ مشروعاً مجانياً جديداً.
2. أضف تطبيق ويب (Web App) وانسخ `apiKey` و `projectId`.
3. أنشئ قاعدة بيانات **Cloud Firestore** من القائمة الجانبية.
4. في تبويب **Rules** لقاعدة Firestore، ضع القاعدة التالية للسماح بالوصول:
```javascript
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /reverse_rooms/{document=**} {
      allow read, write: if true;
    }
  }
}
```
5. افتح اللعبة واضغط على أيقونة الإعدادات ⚙️ أعلى اليسار، والصق الـ `apiKey` و `projectId`، واضغط **حفظ**.
*(يتم حفظ الإعدادات في متصفحك تلقائياً دون الحاجة لتعديل الكود).*
